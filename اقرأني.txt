برنامج الإجازات — نسخة سطح المكتب (Windows)
================================================

المحتويات:
- leave_app_desktop.py   → واجهة البرنامج (Tkinter)
- leave_logic.py          → منطق البيانات وقاعدة البيانات (SQLite)
- build_exe.bat           → سكربت يحوّل البرنامج تلقائياً لملف exe واحد
- requirements.txt        → لا يحتاج أي مكتبات خارجية (Tkinter و SQLite مدمجتان في بايثون)


الطريقة 1: تشغيل البرنامج مباشرة بدون تحويله لـ exe
-----------------------------------------------------
1. ثبّت بايثون من https://python.org (إذا ما كان مثبت) — تأكد تختار
   "Add Python to PATH" أثناء التثبيت.
2. افتح موجّه الأوامر (Command Prompt) داخل مجلد البرنامج.
3. شغّل:
       python leave_app_desktop.py


الطريقة 2: تحويله لملف exe واحد (مستقل، بدون حاجة لبايثون على الجهاز الآخر)
-----------------------------------------------------------------------------
1. تأكد إن بايثون مثبت على جهازك (الخطوة 1 أعلاه).
2. دبل كلك على build_exe.bat — بيثبت PyInstaller تلقائياً ويبني الملف.
   (أو يدوياً من موجّه الأوامر:
        pip install pyinstaller
        pyinstaller --onefile --windowed --name "برنامج الإجازات" leave_app_desktop.py
   )
3. الملف الجاهز راح تلقاه في: dist\برنامج الإجازات.exe
4. انسخ هذا الملف وشغّله على أي جهاز ويندوز — ما يحتاج تثبيت بايثون هناك.

ملاحظات مهمة
-------------
- البيانات تُخزَّن في: ‎%USERPROFILE%\LeaveApp\leave_app.db‎
  (يعني كل جهاز يحتفظ ببياناته الخاصة — هذا برنامج مستقل بدون سيرفر مشترك،
  مو متزامن بين الأجهزة المختلفة).
- لو تبي نظام يتشارك فيه المدير والموظفين نفس البيانات عبر أجهزة مختلفة،
  هذا يحتاج تصميم مختلف (سيرفر مركزي)، تقدر تطلبه مني في محادثة منفصلة.
- أول تشغيل ينشئ قاعدة البيانات تلقائياً مع الحسابات التجريبية أعلاه.
- الكود كامل ومفتوح — تقدر تعدّل الألوان، الرصيد الافتراضي (DEFAULT_BALANCE
  في leave_logic.py)، أو تضيف ميزات بنفسك.
